# Job Application Autofill Privacy Policy

Last updated: May 18, 2026

Job Application Autofill is a local-first browser extension that helps users review and fill job application forms.

## Data Stored Locally

The extension stores candidate profile data locally in the user's browser using IndexedDB. Profile records are encrypted with a passphrase before they are saved. Site mapping overrides and extension settings are also stored locally.

The extension does not operate a backend service, does not sync data to cloud storage, and does not transmit profile data to the developer or any third party.

## Site Access

The extension requests access only to supported applicant tracking system pages when the user chooses to scan a page. The extension uses this access to detect visible form fields and prepare a reviewable fill plan.

LinkedIn is restricted to copy-assist only. The extension does not inject scripts into LinkedIn, scan LinkedIn pages, modify LinkedIn pages, or automate LinkedIn activity.

## User Control

The extension does not submit forms automatically. Users review fill plans before filling fields and submit applications manually. File uploads, sensitive questions, account creation, login pages, CAPTCHA, assessments, and unsupported dynamic widgets require manual user action.

## Telemetry And Remote Code

The extension does not collect telemetry, analytics, crash reports, or behavioral data. It does not load or execute remote code.

## Data Deletion

Users can delete all local extension data from the side panel. This clears encrypted profiles, legacy profile records, site overrides, selected profile metadata, passphrase configuration state, and first-run consent status.

## Passphrase Recovery

The extension does not store or transmit the user's passphrase. If the passphrase is lost, encrypted profile data cannot be recovered.
